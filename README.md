I got into programming through tinkering with Arduino — hardware that blinks is a very good motivator when you're eleven and nothing else you write does anything visible. That turned into Python, then into iOS once I realised I could build things I'd actually carry around with me.

I like projects where the result is tangible: an app I can hand to someone, a script that saves me an hour of homework admin, a circuit that does one small thing well.
