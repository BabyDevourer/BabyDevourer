About

I'm a secondary school student in Ho Chi Minh City who got into programming through tinkering with Arduino and never really stopped. These days most of my time goes into iOS development — I'm building RecipeApp, a SwiftUI app for saving and scaling recipes, as a way to learn the framework properly rather than just following tutorials.

I like projects where I can see the thing working: hardware that blinks, apps I can hold, scripts that save me an hour. If you're working on something in that space, I'd love to hear about it.

Currently: building RecipeApp in SwiftUI · learning Swift concurrency and Core Data · open to collaborating on beginner-friendly iOS or Arduino projects.
